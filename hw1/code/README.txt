# CS180 / CS280A — Project 1: Images of the Russian Empire

## Overview

This project reconstructs color images from Prokudin-Gorskii glass plate photographs. Each photograph contains three grayscale images captured through different color filters: **blue, green, and red**. The goal is to align these three channels and combine them into a single color image.

---

## How to Run

Install the required packages:

pip install numpy scikit-image matplotlib

Then run:

python3 hw1/code/main.py

**Change imname in main.py to process a different image.**
